# Docker for vIDE

See and control your local containers without leaving the editor. Containers started by Docker Compose are grouped by project.

## What it does

- Start, stop, restart and remove containers, one at a time or a whole Compose project
- Follow `docker logs -f` in an editor tab, with copy, zoom and Send to Claude
- A badge with the number of running containers
- Per-container memory use

## Needs

Docker Desktop, or the `docker` CLI on your PATH.

## Settings

Settings › Docker controls the badge and how memory is shown. Uninstall the app from the Store to turn Docker off.
